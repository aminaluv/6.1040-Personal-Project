# Catalog

Anyone can [list the catalog](reaction:Catalog.List). The [book list](former:Catalog.BookList)
gathers every described book in title order.

```endpoints
Catalog.List at /catalog/list
```

A reader can [open a book's First Impression card](reaction:Catalog.Card). The
[First Impression card](former:Catalog.FirstImpression) gathers the book's details, its
characters, and its scores on each criterion.

```endpoints
Catalog.Card at /catalog/card
```
